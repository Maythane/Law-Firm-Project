16 · สรุป + งานต่อยอด

OOP ที่โชว์ได้ กับขั้นต่อไปที่ทำได้จริง

  • Inheritance — Person/SystemUser/Client แยกตาม is-a จริง (ลูกความไม่ใช่ user)
  • Polymorphism — home_url() / reminder_lead_days() ไม่มี if ชนิดในผู้เรียก
  • Encapsulation — สถานะคดีแตะตรงไม่ได้ ผ่าน advance_status() อย่างเดียว
  • Separation — api → repository → domain ทิศทางเดียว ตรวจด้วย grep ได้

ต่อยอด: แจ้งเตือนทางอีเมล/ไลน์ · ปฏิทินซิงก์ · สิทธิ์ละเอียดต่อคดี (ตอนนี้ manager เห็นหมด)

จบด้วยประโยคเดียว: ระบบนี้กฎอยู่ใน object ไม่ได้อยู่ใน if — แล้วเปิดรับคำถาม
