## ข้อความเชิญตอบแบบสอบถาม

ส่งข้อความนี้ก่อน แล้วค่อยส่งลิงก์ตามไปในข้อความถัดไป เพื่อให้ผู้รับรู้ตัวก่อนว่าเป็นอะไร ไม่ใช่ลิงก์โผล่มาเฉย ๆ
แทนที่ `[มหาวิทยาลัย]` และ `[ลิงก์]` ก่อนส่ง

### แบบ ก — ส่งถึงคนที่รู้จักหรือมีคนแนะนำต่อ

```
สวัสดีครับ ผมเมทนี พูลสมบัติ นักศึกษา [มหาวิทยาลัย] ครับ

ตอนนี้กำลังทำโปรเจกต์ในวิชาเรียน ออกแบบระบบช่วยทนายจัดการคดีที่รับผิดชอบและตารางวันนัด
เลยอยากขอความอนุเคราะห์สอบถามจากคนที่ทำงานจริงสักเล็กน้อยครับ

เป็นแบบสอบถามสั้น ๆ ใช้เวลาประมาณ 10 นาที ตอบแบบไม่ระบุชื่อ
และไม่มีข้อไหนที่ต้องกรอกชื่อคดีหรือชื่อลูกความเลยครับ

ถ้าสะดวก รบกวนขอความกรุณาด้วยนะครับ ขอบพระคุณมากครับ
```

### แบบ ข — ส่งถึงผู้ที่ไม่เคยรู้จักกันมาก่อน หรือส่งในกลุ่มวิชาชีพ

```
เรียน ท่านทนายความ

ผมนายเมทนี พูลสมบัติ นักศึกษา [มหาวิทยาลัย] ขออนุญาตรบกวนเวลาสักครู่ครับ

ผมกำลังทำโปรเจกต์ในรายวิชาการเขียนโปรแกรมเชิงวัตถุ โดยออกแบบระบบสำหรับช่วยทนายความ
จัดการคดีที่ได้รับมอบหมายและตารางวันนัด จึงขอความอนุเคราะห์ข้อมูลจากผู้ปฏิบัติงานจริง
เพื่อให้ระบบที่ออกแบบตรงกับการทำงานจริง ไม่ใช่การคาดเดาเอง

แบบสอบถามใช้เวลาประมาณ 10 นาที ตอบโดยไม่ระบุตัวตน ไม่มีคำถามข้อใดที่ต้องระบุชื่อคดี
ชื่อคู่ความ หรือหมายเลขคดี และคำตอบจะใช้ประกอบงานการศึกษาเท่านั้น
ส่วนคำถามเรื่องค่าตอบแทนเป็นคำถามที่ข้ามได้ทุกข้อครับ

หากท่านสะดวก ผมจะขอส่งลิงก์แบบสอบถามให้ในข้อความถัดไปครับ
ขอบพระคุณอย่างสูงครับ
```

### แบบ ค — สั้นที่สุด สำหรับส่งต่อในแชต

```
รบกวนขอความช่วยเหลือครับ ผมทำโปรเจกต์เรียน ออกแบบระบบช่วยทนายจัดตารางวันนัดและคดีที่ถืออยู่
ขอสอบถามคนที่ทำงานจริงประมาณ 10 นาที ตอบไม่ระบุชื่อ ไม่ต้องกรอกข้อมูลคดีใด ๆ ครับ
```

### ข้อความตามหลังตอนส่งลิงก์

```
ลิงก์แบบสอบถามครับ
[ลิงก์]

หากข้อใดไม่ตรงกับลักษณะงานของท่าน ข้ามได้เลยครับ
ขอบพระคุณที่สละเวลาครับ
```

### ข้อความติดตามหลังผ่านไป 5–7 วัน

```
สวัสดีครับ รบกวนติดตามแบบสอบถามที่เคยส่งไว้อีกครั้งครับ
หากท่านตอบไปแล้ว ต้องขออภัยที่รบกวนซ้ำ และขอบพระคุณมากครับ
หากยังไม่ได้ตอบและพอมีเวลา รบกวนขอความกรุณาด้วยนะครับ ใช้เวลาประมาณ 10 นาทีครับ

[ลิงก์]
```

**ข้อควรระวังตอนส่ง**

- อย่าส่งลิงก์มาพร้อมข้อความแนะนำตัวในทีเดียว ถ้าผู้รับไม่รู้จักกันมาก่อน ลิงก์ที่โผล่มาพร้อมข้อความยาวมักถูกมองว่าเป็นข้อความหลอกลวง
- อย่าใช้คำว่า "วิจัย" ถ้ายังไม่ได้ผ่านการพิจารณาจริยธรรมการวิจัยในมนุษย์ ใช้คำว่าโปรเจกต์รายวิชาตามความจริง
- บอกระยะเวลาที่ใช้ตอบทุกครั้ง เป็นสิ่งที่คนตัดสินใจจากมันมากที่สุด
- ถ้ามีอาจารย์หรือผู้ใหญ่ในวงการแนะนำต่อ ให้ระบุชื่อผู้แนะนำในบรรทัดแรก จะได้รับการตอบกลับสูงกว่ามาก

บันทึกไว้ตามที่ฟอร์มเป็นจริง ณ วันที่ซิงก์ไฟล์นี้
